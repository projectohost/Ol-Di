# Sport Arena

Браузерний симулятор спортивних подій із віртуальним балансом.

## Реалізовано

- новий спортивний захід кожні 15 секунд;
- окремий ігровий годинник, який не залежить від реального часу;
- 1 ігрова хвилина = 0,1 секунди реального часу (швидкість ×600);
- можливість вручну встановити потрібний ігровий час;
- випадковий результат із вагою `1 / коефіцієнт`, нормалізованою між варіантами;
- окремі анімації для футболу, баскетболу, Формули 1, тенісу, хокею, боксу та волейболу;
- коректне списання ставки під час її прийняття та виплата `ставка × коефіцієнт` у разі виграшу;
- збереження балансу, рівня, XP і часу в `localStorage`;
- адаптивний інтерфейс для телефона та комп’ютера.

## Запуск без сервера

Відкрийте `index.html` у браузері. Файл `cataloge.html` залишено для сумісності зі старою структурою проєкту.

## Запуск через Python

```bash
pip install -r requirements.txt
python server.py
```

Потім відкрийте `http://127.0.0.1:5000`.

> Проєкт використовує лише віртуальні кредити. Для системи з реальними коштами результат, баланс і прийняття ставок повинні повністю оброблятися на захищеному сервері, а не в браузері.
